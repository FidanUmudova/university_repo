# Git and GitHub Glossary

* **Repository (Repo)**: A folder or storage space where your project files and their history live. (Example: `university_repo`)
* **Fork**: A personal copy of someone else's repository created on your own GitHub account. (Example: Forking a mentor's project to work on it)
* **Clone**: Downloading a copy of a remote GitHub repository onto your local computer. (Example: `git clone <url>`)
* **Branch**: A parallel version of a repository, used to work on new features without affecting the main code. (Example: `feat/glossary`)
* **Commit**: A snapshot or saved state of your changes in the repository history. (Example: `git commit -m "add glossary"`)
* **Push**: Sending your local branch commits to the remote repository on GitHub. (Example: `git push origin feat/glossary`)
* **Pull**: Fetching and downloading changes from the remote repository and merging them into your local branch. (Example: `git pull origin main`)
* **Pull Request (PR)**: A proposal to merge your branch changes into the main repository, open for review. (Example: Asking a teammate to review your code)
* **Rebase**: The process of moving or combining a sequence of commits to a new base commit to keep a clean history. (Example: `git rebase origin/main`)
* **Staging Area**: A middle ground where files are prepped and gathered before making a commit. (Example: Running `git add .` puts files here)
