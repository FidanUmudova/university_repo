# 🤝 Contributing Guide

## 1. Fork the repo
Click Fork on GitHub and clone your fork locally.

## 2. Create a branch
Always create a new branch before working:
git checkout -b feat/your-task

## 3. Commit rules
Use clear messages:
feat: add feature
fix: solve bug
docs: update documentation

## 4. Push changes
git push -u origin your-branch-name

## 5. Pull Request rules
- Open PR to main branch
- Use clear title
- Link the issue (Closes #issue-number)
- Do not merge your own PR

## 6. Review process
Wait for at least one teammate to review your PR before merging.
